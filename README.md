## 🎨 Design

Paleta de cores inspirada em um estilo corporativo e profissional:
- **Navy Blue (#1e3a5f)** - Cor principal, transmite confiança e profissionalismo
- **Steel Blue (#5b9bd5)** - Cor de destaque, moderna e elegante
- Design minimalista e clean com foco em espaços em branco
- Tipografia corporativa com fontes serifadas para títulos

## 🚀 Tecnologias Utilizadas

- HTML5 semântico

- JavaScript Vanilla (ES6+)

- Google Fonts (Inter)

## 🔧 Como Usar

1. Clone o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Para personalizar, edite:
   - `index.html` - conteúdo e estrutura
   - `css/style.css` - estilos e cores
   - `js/main.js` - array de projetos e funcionalidades

## 📝 Personalização

### Adicionar Novos Projetos

Edite o array `projetos` no arquivo `js/main.js`:

```javascript
{
    id: 7,
    titulo: "Seu Novo Projeto",
    descricao: "Descrição do projeto",
    tecnologias: ["HTML", "CSS", "JS"],
    githubLink: "https://github.com/...",
    demoLink: "https://...",
    icone: "🎯"
}
```

### Alterar Cores

Edite as variáveis CSS em `css/style.css`:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    /* ... outras cores */
}
```
